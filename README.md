# inaai-log-tracker
Aplikasi web dashboard yang dirancang khusus untuk mengoptimalkan pelacakan gangguan secara berkala.

Proyek ini dibangun dari awal selama fase 2 kompetisi. Sesuai dengan kebijakan AI dan Plagiarisme InaAI, kerangka awal proyek ini menggunakan template open-source publik standar:
* **Frontend**: `create-vite` (react.js)
* **Backend**: `go mod init` dengan Echo Framework (v4)
